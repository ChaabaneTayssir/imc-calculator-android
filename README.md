# IMC Calculator – Android App

Android app to calculate and track Body Mass Index (BMI / IMC), with personalized recommendations.

## Tech stack
Kotlin · Jetpack Compose · Firebase · Clean Architecture (data / domain / ui) · MVVM

## Run the project
1. Open the project in Android Studio.
2. Add your own `google-services.json` file in the `app/` folder (from your Firebase project).
3. Run on an emulator or an Android device.
